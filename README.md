# 소수 나눗셈 탐험대

초등학교 6학년 수학 수업용 Streamlit 학습 앱입니다. 리본과 주스를 나누는 생활 속 상황과 직접 제작한 SVG 그림을 통해 소수 나눗셈의 뜻과 계산 원리를 탐험합니다.

## 설치 및 실행

Python 3.9 이상에서 프로젝트 폴더로 이동해 다음 명령을 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시되는 로컬 URL(기본값 `http://localhost:8501`)을 엽니다.

## 수업 흐름

1. 학습 안내에서 오늘의 목표를 확인합니다.
2. **똑같이 나누기**에서 리본을 나누고 입력한 수에 맞춰 조각 그림과 계산 결과를 살펴봅니다.
3. **소수로 몇 번 나눌 수 있을까**에서 주스를 컵에 나누어 담습니다.
4. **소수점을 없애는 마법**에서 두 수에 10 또는 100을 곱해 몫이 변하지 않는 원리를 단계별로 확인합니다.
5. 세 가지 탐험 미션에 도전해 진행 상황과 최종 성공을 확인합니다.
6. 학습 정리와 마무리 질문으로 배운 내용을 되짚습니다.

계산에는 `Decimal`과 정확한 분수 표현을 사용합니다. 입력값과 활동 진행 상황은 Streamlit 세션 상태에 보존됩니다. 그림은 앱 코드 안의 SVG로 생성하며 외부 이미지 서비스나 유료 API를 사용하지 않습니다.

## 배포

Streamlit Community Cloud 또는 Streamlit을 실행할 수 있는 서버에 저장소를 연결하고 `streamlit_app.py`를 앱 진입점으로 지정합니다. 종속성은 `requirements.txt`에서 설치합니다.
