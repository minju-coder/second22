# 소수 나눗셈 탐험대

초등학교 6학년 학생이 생활 속 상황과 시각 자료를 통해 소수 나눗셈의 의미와 계산 원리를 탐험하는 Streamlit 학습 앱입니다.

## 실행 방법

Codespaces 터미널에서 프로젝트 폴더에 있는지 확인한 뒤 실행합니다.

```bash
python -m streamlit run streamlit_app.py
```

필요한 라이브러리는 `requirements.txt`에 기록되어 있습니다. 환경에 아직 Streamlit이 없다면 다음 명령으로 설치할 수 있습니다.

```bash
python -m pip install -r requirements.txt
```

## 앱에서 할 수 있는 활동

- 리본을 똑같이 나누고 주스를 컵에 담으며 소수 나눗셈을 연습합니다.
- 10 또는 100을 곱해 나눗셈의 몫이 바뀌지 않는 원리를 확인합니다.
- 세 가지 탐구 미션으로 배운 내용을 적용합니다.
- 화면의 그림은 Streamlit 기본 요소로 표시해 외부 이미지나 사용자 정의 HTML에 의존하지 않습니다.
